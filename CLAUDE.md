# Project instructions — Bark & Chomp

## Keep handoff.md current

`handoff.md` in this directory is the session-to-session handoff doc. It must always reflect the true current state of the project.

- At the **start** of every session, read `handoff.md` first to pick up context.
- At the **end** of every session (or after any meaningful chunk of work — a milestone completed, a decision made, a phase gate passed/failed), update `handoff.md`:
  - Move completed items from "not done" to "done," or check them off.
  - Update the "What's next" section if priorities shifted.
  - Add anything learned that the next session needs (decisions, gotchas, blockers).
  - Bump the "Last updated" date at the top.
- Do this proactively — don't wait for the user to ask "update the handoff doc."
- If work diverges from the plan in `bark_and_chomp_project_plan.md`, note the divergence and why in `handoff.md` rather than silently drifting.
